# tienganh6-speaking

Luyện nói Tiếng Anh 6 (Global Success) theo Unit – Speaking Quest.

- 12 Unit × 4 bài nói: **Basic 1, Basic 2** (theo SGK) và **Advanced 1, Advanced 2** (chương trình bổ sung nâng cao)
- 4 bài ôn: giữa kì 1 (sau Unit 3), cuối kì 1 (sau Unit 6), giữa kì 2 (sau Unit 9), cuối kì 2 (sau Unit 12)
- Trang học sinh: https://nguyenthuthuythbt.github.io/tienganh6-speaking/

## Cấu trúc
```
index.html            trang chủ cho học sinh
links.html            bảng link để cô copy gửi học sinh
hk1/unit1 … unit6     basic-1.html basic-2.html advanced-1.html advanced-2.html
hk1/giua-ky-1, cuoi-ky-1   on-thi.html
hk2/unit7 … unit12, giua-ky-2, cuoi-ky-2
```

## Cách thêm bài
Thay file cùng tên trong thư mục (ví dụ `hk1/unit4/basic-1.html`), Commit + Push; link giữ nguyên. File chưa thay đang là trang "Bài này chưa mở".

Không đổi tên file/thư mục sau khi đã gửi link.
